# Aponto — downloads

Installers for **Aponto**, the desktop app that tracks students and expenses and texts each parent their monthly and yearly summary from your own Android phone.

➡️ **[Download the latest release](https://github.com/tiagoxalmeida/aponto-releases/releases/latest)**

| System | File |
|---|---|
| Windows 10/11 (64-bit) | `…-win-x64-installer.exe` or `…-win-x64-portable.exe` |
| macOS (Apple Silicon & Intel) | `…-mac-universal.dmg` or `.zip` |
| Linux (x86_64) | `….AppImage` or `….deb` |

Aponto needs a license key — get one at **[store.tiago-almeida.pt](https://store.tiago-almeida.pt/)**.

This repository only hosts the installers; the source code is private.
